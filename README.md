# Lichii Shader Sync

</div>

Lichii Shader Sync was a small Windows and Linux app for the Lichii Switch 2 emulator. It
downloaded shader caches shared by other players of The Legend of Zelda: Ocarina of Time and
merged them into your own, so the game stuttered less the first time you played through an area.
It supported Lichii's newer shader cache (build 130 and up), turned on Lichii's shader precaching,
and could keep Ocarina of Time saves in sync between emulators.

**This project has moved and is no longer maintained here.** Its releases and shader packs have
been removed from this repository.
